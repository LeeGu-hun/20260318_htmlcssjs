  1. 이벤트를 처리하는 방식
    • Event Handler Property 방식 :: 가장 마지막 정의된 것 적용

      • 스크립트의 요소.onclick, onkeypress, onchange, onmouseover, ...

    • addEventListener("click", 콜백함수) 정의(권장) :: 누적

      • addEventListener방식은 이벤트가 누적된다.

    • Inline Event Handler

      • <button onclick="alert('hello')">버튼</button>

  2. 이벤트의 전파 3단계
    • Capturing Phase(캡쳐링) :: 부모 => 자식
    • Target Phase(타겟) :: 타겟된 실제 요소
    • Bubbling Phase(버블링) :: 자식 => 부모
