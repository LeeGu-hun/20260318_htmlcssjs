조건문(Condition) :: if, if else, if else if, 중첩 if, switch case문

  • if
    •       if(조건) {명령문}
  • if else
    •       if(조건) {
        명령문 // 조건이 참일 경우
      } else {
        명령문 // 조건이 거짓일 경우
      }
  • if else if
    •       if(조건1) {
        명령문 // 조건이 참일 경우
      } else if(조건2) {
        명령문 // 조건2일 경우
      } else if(조건3) {
        명령문 // 조건3일 경우
      } else {
        명령문 // 거짓일 경우
      }
