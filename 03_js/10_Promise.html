Promise 객체와 fetch-then

homeHome

  • Promise가 필요한 이유는 비동기(Asynchronous) 작업을 위해서 이다.
  • Promise가 중요한 진짜 이유: 콜백 지옥 해결
    •       setTimeout(() => {
        console.log("1번 작업 완료");

        setTimeout(() => {
          console.log("2번 작업 완료");

          setTimeout(() => {
            console.log("3번 작업 완료");
          }, 1000);

        }, 1000);

      }, 1000);
      ================ 개선 후 ================ 
      new Promise(function(resolve) {
        resolve(10);
      })
        .then(function(result) {
          console.log(result); // 10
          return result * 2;
        })
        .then(function(result) {
          console.log(result); // 20
          return result * 3;
        })
        .then(function(result) {
          console.log(result); // 60
        });
  • Promise의 3가지 상태 (States)
    1. Pending (대기): 비동기 처리가 아직 완료되지 않은 초기 상태 (진동벨을 막 받은 상태)
    2. Fulfilled (이행): 비동기 처리가 성공적으로 완료되어 결과 값을 반환한 상태 (음식이 나온 상태)
    3. Rejected (거부): 비동기 처리가 실패하거나 오류가 발생한 상태 (재료 소진으로 주문이 취소된 상태)
