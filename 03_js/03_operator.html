    Truthy value

    1. true
    2. 0을 제외한 정수, 실수, Infinity, -Infinity
    3. 빈문자열("", '')을 제외한 모든 문자열
    4. 참조형 객체(Object, 내장객체, 배열, class)
    5. {} 빈 객체, [] 빈 배열
    6. function
    7. DOM, BOM 사전 정의된 객체들

    Falsy value

    1. false
    2. undefined, null
    3. NaN (Not a Number)
    4. 0, -0
    5. "", '' 빈문자열
    6. document.all, alert() 반환되는 값이 없어서 undefined가 됨
