반복문 :: loop ( for, while, do while, for in )

반복문은 규칙성을 찾아야 한다. 변인자는 초기값, 조건, 증감에 대한 설정이 필요.

변인자의 3가지 요인이 다르면 반복문도 그만큼 중첩된다.

    •       for(초기값; 조건; 증감) {
        명령문
      }
  • while
    •       while(조건) { }
  • do while :: 무조건 실행한 후 조건을 따짐
    •       do {
        명령문들
      } while(조건)
